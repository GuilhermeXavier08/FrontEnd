Situação de Aprendizagem 2 - Somativa - JavaScript

O nosso projeto possui uma tela inicial com todos os projetos que concluímos. O primeiro projeto que fizemos foi a lâmpada, onde implementamos funções para acender, apagar, quebrar e trocar a lâmpada, e cada uma dessas opções possui uma imagem correspondente para representar visualmente o estado da lâmpada. 
O segundo projeto foi um contador, onde usamos funções para aumentar o valor, diminuir o e resetá-lo, permitindo que o usuário controle facilmente o valor do contador. Por fim, fizemos o jogo de JoKenPo, onde o jogador pode escolher entre Pedra, Papel ou Tesoura e competir contra o computador. 
O código do JoKenPo inclui funções para capturar as escolhas, determinar o vencedor da rodada, e atualizar os contadores de vitórias, derrotas e empates, exibindo as imagens e os resultados de forma interativa e divertida.
Cada um desses projetos utiliza conceitos básicos de JavaScript e manipulação do DOM, proporcionando uma experiência prática de programação e uma boa base para desenvolvimentos futuros. A nossa maior dificuldade foi compreender a lógica de programação de cada projeto, especialmente ao lidar com os diferentes conceitos e funções envolvidas em cada um. Esse processo demandou um tempo considerável de aprendizado e prática, o que fez com que a criação dos três projetos fosse mais desafiadora do que o esperado. No entanto, ao longo do desenvolvimento, conseguimos superar essas dificuldades, o que resultou em um grande aprendizado e em uma experiência muito enriquecedora.
